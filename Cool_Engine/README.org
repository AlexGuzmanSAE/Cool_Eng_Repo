* Descripción
Cool Engine es un proyecto pensado para el desarrollo sencillo y eficiente proporcionado por Raylib para juegos pequeños y multiplataforma. Con uso de C++ moderno y una arquitectura robusta alrededor de Lua como lenguage de Scripting para gameplay.

* Características Principales
- Característica 1 :: Simple, multiplataforma, versátil.
- Característica 2 :: Utiliza C++ moderno en su justa medida donde es necesario para sumar a la arquitectura.
- Escalabilidad :: Al usar Lua como lenguaje de scripting, el motor tiene una clara diferenciación entre, C++, rápido y versátil, y Lua, simple, embebido y fácil de desarrollar en el.

* Tecnologías Utilizadas
- *Lenguaje:* =C++ / Lua=
- *Framework:* =Raylib, Box2D=
- *Herramientas:* CMake
